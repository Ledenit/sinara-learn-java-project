### Что я сделал
Я реализовал приложение с разделением прав доступа с использованием Spring Security  
Для разграничения доступа я использовал аннотацию `@RolesAllowed`, которая применена к методам контроллера UserController и ограничивают доступ к приватным эндпоинтам на основе ролей пользователей  

Контроллер `UserController` реализует три эндпоинта:
* `/public/api` — возвращает сообщение, доступное всем
* `/support/api` и `/admin/api` — возвращают JSON с именем пользователя и его ролью

Конфигурацию безопасности я выполнил в классе `SesurityConf`, где в методе `securityFilterChain` настроил правила доступа к маршрутам:
* `/public/api` — доступ открыт для всех без авторизации
* `/support/api` — доступ только для пользователей с ролью **support**
* `/admin/api` — доступ только для пользователей с ролью **admin**

Пользователей я храню используя `InMemoryUserDetailsManager`, в котором их три:
* support_skb с ролью support
* admin_skb с ролью admin
* user с ролью user

Для хеширования паролей использован `BCryptPasswordEncoder` (бин `passwordEnc`)
