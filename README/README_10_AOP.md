### Что я сделал
С помощью AOP я реализовал демонстрационное SpringBoot-приложение, в котором происходит подсчет количества
обращений к АПИ методам, и если количество обращений достигнет максимального, то выполнение метода не допускается  

Для этого я:
* Создал аннотацию `@RequestLimit` для пометки методов, вызовы которых нужно ограничивать
* В `application.properties` задал максимальное число запросов
* Написал аспект `RequestLimitAspect` с использованием аннотации `@Before`
* Реализовал исключение `LimitRequestException`
* Создал `AOPService` с методом `doMonkeyWork()`, помеченным `@RequestLimit`, чтобы продемонстрировать работу аспекта
* Добавил `Controller` с эндпоинтом `/api/monkey-work`, который вызывает сервис и показывает, что после `api.max_calls` запросы блокируются
